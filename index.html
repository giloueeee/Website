Voiture miniature autonome

Classification de scores bancaires

Classification multiclasse de l’éligibilité au crédit via XGBoost en environnement de données dégradées. Le projet a consisté à traiter une base de données brutes présentant de fortes lacunes.

Sélection des features, nettoyage des données numériques, encodage de données textuelles, imputation des valeurs manquantes, création d'un modèle avec XGBoost, évaluation du modèle, Itération de différents hyperparamètres.

Résultat : une précision moyenne de 80%

  • Python
  • XGBoost
  • Github
  • Pandas
  • Seaborn
  • Matplotlib
